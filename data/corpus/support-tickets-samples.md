# Resolved Support Tickets (KB-TIX-09)

## Ticket #48211 — Bulb unreachable after router upgrade
Customer replaced their ISP router and all 6 bulbs went offline (LL-E20). Agent confirmed the new router broadcast a combined 2.4/5 GHz SSID with band steering. Resolution: customer enabled a separate 2.4 GHz SSID, re-ran setup on one bulb; remaining bulbs reconnected automatically once the SSID matched the original network name. Tip: keeping the same SSID and password as the old router avoids re-pairing entirely.

## Ticket #48390 — Refund not received after 9 days
Customer returned an LL-H300, refund approved but not visible. Agent verified refund was issued on day 6 to a credit card. Bank confirmed the card had been cancelled in the interim, so the issuer rerouted funds; arrived day 11. Resolution note: when a refund goes to a closed card, the bank either forwards to the replacement card or mails a check — LumenLeaf cannot redirect it to a different payment method once issued.

## Ticket #48677 — Plug trips on a 1500W space heater
Customer reported repeated LL-E45 overload errors with a 1500W heater on an LL-P50. Diagnostics showed startup inrush current spiking above 1800W-equivalent. Resolution: this is expected behavior for resistive heaters with high inrush; agent advised against using smart plugs with space heaters per UL safety guidance, refunded the plug as a goodwill gesture outside the return window.

## Ticket #48702 — HomeKit code not accepted
Customer couldn't add LL-B200 to Apple Home; setup code rejected. Agent identified the bulb was paired previously to another Apple ID and not removed. Resolution: factory reset the bulb (3x power cycle), removed stale accessory from the old Apple Home, re-paired successfully via the LL-H300 hub.

## Ticket #48850 — Wants to return after 45 days, opened box
Customer requested a refund 45 days post-delivery. Per POL-RET-02 the 30-day refund window had passed but the 60-day store-credit window applied. Resolution: issued store credit minus the $6.50 label fee; customer used credit toward an LL-B200 two-pack.
